§01 · problem path
./problem.md one scalar pde; the whole difficulty is a thin moving front.

nonlinear_convection_diffusion

One field u(x,t) on the unit interval, marched to t = 15. Transport is the Burgers term, so the profile steepens on itself. Diffusion is nonlinear and self-limiting, shutting down where u is large. A logistic source pumps the field toward u = 1 wherever it is already non-zero. Inlet at zero, outlet zero-gradient, Gaussian pulse to start.

  u_t + u u_x  =  d/dx[ D(u) u_x ]  +  S(u)

  D(u) = nu / (1 + b u^2)      nu = 0.001    b = 2
  S(u) = a u (1 - u)           a  = 1.5

  u(0,t) = 0     u_x(1,t) = 0     u(x,0) = Gaussian pulse
  0 <= x <= 1    0 <= t <= 15

The three terms fight each other. Convection sharpens the profile, diffusion is weakest precisely where the sharpening is worst, and the source fills in behind. What comes out is a thin travelling front — and that front is the only hard thing in the problem, so it is what sets the mesh.

So the real question was never whether it runs. It was how fine the grid has to be before the answer stops moving — and I answered that with a nested refinement study instead of by eye.

§02 · method path
./pipeline/ fortran marches; python reads the manifest and draws.

maccormack_and_the_pipeline

The kernel is a MacCormack predictor–corrector: a forward-difference predictor, a backward-difference corrector, and the average of the two. The diffusion term is written conservatively — D is evaluated at the cell faces and the flux is differenced across them, so the discrete operator telescopes instead of leaking mass at the front.

Time step comes from one rule at every grid, dt = σ·Δx²/(Δx + 2ν) with σ = 0.5. That is an empirical limit for this scheme, not a proof — so I measured it (§08) rather than trusting it.

§03 · decisions path
./CHANGELOG.md nested grids · one Δt rule · 6401 as the reference.

tradeoffs_actually_made

  1. grid · nested

    Nested grids, not arbitrary ones.

    Nx = 101, 201, 401, 801, 1601, 3201, 6401 — every coarse node is also a node of every finer grid. Norms are taken at coincident points with no interpolation, so the number I report is a grid-to-grid difference with no interpolation error mixed in — an estimate of discretisation error, not the error against an exact solution.

  2. dt · sigma

    One time-step rule, with margin.

    Δt = σ·Δx²/(Δx + 2ν) at σ = 0.5 everywhere. The stability sweep says Nx = 101 still finishes at σ = 1.25 and blows up at σ = 1.5, so the baseline keeps a factor of about 2.5 in hand — cheap insurance on a run that costs seconds.

  3. ref · 6401

    Nx = 6401 as the error reference.

    With 3201 as the reference the finest grid pair misses the tol/4 self-consistency gate in L∞. Moving the reference one level finer costs 79 s of wall clock — every other run in the sweep is under 10 — and the gate then passes at 6.86e-4 against 2.5e-3.

  4. order · smooth

    Order measured before the front exists.

    Observed order is taken at t = 0.05, while the field is still smooth: 1.89 → 1.96 → 2.00 → 2.07 across successive refinements. Measured through the front it reads lower, which is honest — the scheme is second order on smooth data, not on a discontinuity.

§04 · outcome path
./STATE.md selected grid Nx = 1601 at tol 1e-2.

key_numbers

25 runs, Nx = 101 through 6401, every one exits clean. At a tolerance of 1e-2 against the reference, the coarsest grid that holds in L∞ is Nx = 1601 — worst-case 3.39e-3, which occurs at t = 0.5 while the front is still forming. In L2 the same tolerance is met at Nx = 201 (9.89e-3), so L∞ is the binding constraint and 1601 is the grid I report on.

§05 · grid study path
./figures/grid/ 7 grids, 2 gates, both passed.

grid_and_time_step_study

Two gates decide whether the study is trustworthy before any grid gets selected. The reference gate compares the two finest grids, 3201 against 6401: 6.86e-4 in L∞ against a budget of 2.5e-3. The temporal gate halves Δt at the selected grid and asks how far the answer moves: 2.12e-4 against 1e-3. Both clear, so the spatial error I quote is not quietly contaminated by the reference or by the time step.

Refinement bites hardest early. The L∞ difference at Nx = 1601 is 2.38e-3 at t = 1 and 2.73e-5 at t = 15 — about 87× smaller once the front has left the domain and the field has settled. That is the whole shape of this problem in one ratio: the grid is paying for the front, not for the steady state.

§06 · space-time path
./figures/viz/ where the error actually lives: a ribbon on the front.

space_time_and_physics

Plotting u over (x, t) is the fastest way to see why the grid study came out the way it did. The front averages a speed of 0.413 and reaches the outlet at t ≈ 1.686; at t = 1 its 10–90% rise is about 8.6e-3 wide, which is under two cells at Nx = 201 and roughly 28 at Nx = 3201. That single number explains the whole convergence table.

The error maps make the same point from the other side: the difference from the reference is not spread over the domain, it is a thin ribbon that traces the front and fades a level at a time as the grid refines. Everything else — characteristics, term balance, the integral budget — is there to check that the physics behind that ribbon is the physics I meant to solve.

§07 · animations path
./figures/anim/ ten clips, muted loops, play on scroll.

animations

Static frames hide the part that matters — how fast the coarse grids drift away from the fine ones and then quietly come back once the front leaves. These are the same runs, re-drawn frame by frame. They start when they scroll into view — unless you have asked your system for reduced motion, in which case nothing moves until you say so — and each one hands you its controls the moment it can play, so it can always be stopped.

§08 · checks path
./figures/checks/ stability sweep · extrema · budget · cost.

checks_and_cost

The time-step rule is empirical, so I mapped it. A separate opt-in sweep of 24 runs over Nx × σ says Nx = 101 survives σ = 1.25 and blows up at σ = 1.5; refining the mesh pushes that boundary up. Running everything at σ = 0.5 therefore sits well inside the stable region on every grid in the study.

Two more things I watch rather than assume. The coarse grids overshoot — Nx = 101 peaks at u = 1.083 and dips to −0.058, both outside the physical range — while Nx = 1601 and finer stay inside [0, 1] to six figures. And the integral budget closes: d/dt ∫u dx tracks the boundary fluxes plus the source with a median residual of 7.5e-6 against a peak rate of 2.9e-1, the exception being the few frames where the front crosses the outlet and the centred time difference sees a kink.

Cost is the reason to stop. Wall clock runs 1.4 s at Nx = 1601, 9.8 s at 3201 and 78.9 s at 6401 — roughly 8× per refinement, because halving Δx also quarters Δt. Paying 56× the run time to move a 3.39e-3 error inside a 1e-2 budget is not a trade I need to make.
