§01 · problem path
./problem.md closed-form is fine. until it isn't.

fracture_cliff

Final project: a 160 × 77 × 0.85 mm soda-lime glass panel dropped onto a rigid floor at flat-face and tilted orientations. Goal — build a fracture map (σmax vs. angle θ and impact velocity v) and bracket the drop height where the panel fails against FT = 220 MPa tensile strength.

Headline result: fracture between v = 7.0–7.1 m/s — a free-fall height of ~8.31 ft (median), worst case at θ = 0°. Any tilt ≥ 15° drops peak σ₁ by 5–10× and stays below FT across the full velocity sweep.

lsdyna_pipeline

Python orchestration in postprocess/sweep.py: clone deck → patch velocity/angle → run LS-DYNA via WSL → extract σ₁max(t) from d3plot with lasso-python → audit against summary.json. A 4×5 grid sweep over θ ∈ {0, 15, 30, 45}° and v ∈ 5000–8000 mm/s, plus implicit modal analysis (NEIG=20 Lanczos) for flexural modes.

§03 · decisions path
./CHANGELOG.md picked → rejected. each line is a deliberate trade.

tradeoffs_actually_made

  1. elform · 16

    ELFORM 16 over ELFORM 2.

    Belytschko-Tsay (ELFORM 2) showed 46% hourglass energy and inflated peak σ₁ to 218 MPa. Full integration (ELFORM 16) drove hourglass to 0% and the true peak to 119 MPa for the same 4 ft drop.

  2. dt · 1µs

    DT = 1×10⁻⁶ s required.

    DT = 1×10⁻⁵ s aliased the sub-microsecond impact peak by ~7%. Refining to 1 µs costs ~16 GB d3plot per run but is necessary for stress-magnitude work.

  3. mat · 280

    Element deletion as fracture observable.

    σ-vs-v curves saturate near FT = 220 MPa without crossing cleanly; MAT_280 element deletion jumps from 0 → 18 elements between v = 7000 and 8000 mm/s, tightening the bracket to ±1.4 inches of drop height.
